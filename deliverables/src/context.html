Inside Nordic Flow: Web UI → API (JSON over HTTP); API → optimisation core (Python calls) and → SQLite (SQL). The core has no web or database code.

Trust gates

1
Data validationEight CSV checks with row-level messages; any error blocks the run.
2
Independent verifierRe-checks demand, supply, capacity and lanes without using the solver.
3
Honest savingShown only against a verified feasible baseline; otherwise the UI says unusable.
4
AI guardrailThe model only rewrites computed facts; a figure not in the facts rejects the text.
5
Approval gateNo export before a planner approves; approved and rejected plans are locked.
6
Audit trailAppend-only events, each hash-linked to the previous one: tamper-evident.
